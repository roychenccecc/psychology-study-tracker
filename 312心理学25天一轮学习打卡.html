固定规则

  • 学习日以早上8:00为界：00:00-07:59完成的内容计入前一天，08:00起计入当天；完成时间仍保留真实时间。
  • 高强度日：周日、周二、周三。
  • 周四上午不排固定任务；周六晚上可顺延安排。
  • 普心和统计保留历史进度；每日复习用碎片化时间处理。
  • 白天时间按碎片化处理，主要用于每日复习和写题。
  • 普心/统计剩余收尾任务放入7月上旬白天碎片栏。
  • 实验：晚上听课 -> 次日白天碎片做题，不另排看书。
  • 发展/教育：晚上听课 -> 次日白天碎片做题，不另排看书。
  • 社会：晚上听课 -> 次日白天碎片做题 -> 当晚继续下一章，不另排看书。
  • 英语：每周日晚上做题1h；优先级最低，可与专业课听课并存，逾期直接跳过而不顺延。
  • 每天不设闭环要求：任务按实际精力独立完成，可以提前多学，也可以少学并留出消化时间。
  • 新科目默认按“实验 -> 发展 -> 教育 -> 社会 -> 测量”串行；一旦实际提前启动后续科目，就按实际进度填入最近空位。
  • 逾期未完成会自动顺延；提前完成会让后续计划自动压紧，做题找最近白天，听课找最近晚上。
